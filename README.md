# 🛒 쇼핑 리스트 (Shopping List App)

필요한 물건을 빠르게 적고 체크하며 관리할 수 있는 가벼운 웹 기반 쇼핑 리스트 앱입니다.
별도의 서버나 빌드 도구 없이 **단일 HTML 파일**로 동작하며, 브라우저의 `localStorage`에 데이터를 저장하기 때문에 새로고침하거나 브라우저를 닫았다 켜도 목록이 그대로 유지됩니다.

## ✨ 주요 기능

- **아이템 추가**: 입력창에 내용을 적고 `추가` 버튼 또는 `Enter` 키로 빠르게 등록
- **체크 / 체크 해제**: 체크박스를 누르면 완료 상태로 표시되고 텍스트에 취소선이 그어짐
- **개별 삭제**: 각 항목 오른쪽의 `✕` 버튼으로 한 건씩 삭제
- **완료 항목 일괄 삭제**: 체크된 항목만 한 번에 비우기
- **카운터**: 전체 항목 수와 완료된 항목 수를 실시간으로 표시
- **자동 저장**: 모든 변경 사항이 `localStorage`에 즉시 저장되어 새로고침에도 데이터 유지
- **빈 상태 안내 메시지**: 아이템이 하나도 없을 때 친절한 안내 문구 표시
- **반응형 UI**: 모바일에서도 자연스럽게 보이도록 viewport와 레이아웃 조정

## 🛠 사용 기술

- **HTML5** — 마크업
- **CSS3** — 그라데이션 배경, 카드 레이아웃, hover/focus 인터랙션
- **Vanilla JavaScript (ES6+)** — DOM 조작, 이벤트 처리
- **Web Storage API (`localStorage`)** — 클라이언트 측 데이터 영속화

> 외부 라이브러리, 프레임워크, 빌드 단계가 전혀 없습니다. `index.html` 하나로 끝.

## 🚀 실행 방법

### 1. 저장소 클론

```bash
git clone https://github.com/hosunyii/shopping-listapp.git
cd shopping-listapp
```

### 2. 브라우저로 열기

`index.html` 파일을 더블클릭하거나, 브라우저에 드래그하여 열면 바로 사용할 수 있습니다.

선택적으로 로컬 서버를 띄우고 싶다면:

```bash
# Python 3가 설치되어 있다면
python -m http.server 8000
# → http://localhost:8000 접속
```

## 📖 사용법

1. 상단 입력창에 추가할 물건의 이름을 입력합니다. (예: `우유`, `달걀 한 판`)
2. `추가` 버튼을 클릭하거나 `Enter` 키를 누르면 목록 하단에 항목이 추가됩니다.
3. 항목 왼쪽의 체크박스를 누르면 **완료 처리**되고 텍스트에 취소선이 표시됩니다.
4. 항목 오른쪽의 `✕` 버튼을 누르면 해당 항목만 **삭제**됩니다.
5. 우측 상단의 `완료 항목 삭제` 버튼을 누르면 체크된 항목들을 **한 번에 정리**할 수 있습니다.

## 💾 데이터 저장 방식

- 모든 항목은 브라우저의 `localStorage`에 `shopping-list-items` 키로 저장됩니다.
- 저장 데이터 구조 예시:

  ```json
  [
    { "id": 1716100000000.123, "text": "우유",   "done": false },
    { "id": 1716100050000.456, "text": "달걀", "done": true  }
  ]
  ```

- 같은 브라우저, 같은 도메인(또는 같은 로컬 파일 경로)에서만 데이터가 공유됩니다. 다른 기기/브라우저와는 동기화되지 않습니다.
- 데이터를 모두 비우고 싶다면 브라우저 개발자 도구 → Application → Local Storage에서 키를 삭제하거나, 사이트 데이터를 지우면 됩니다.
